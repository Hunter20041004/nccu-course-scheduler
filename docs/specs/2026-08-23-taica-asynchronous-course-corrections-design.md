# TAICA 非同步遠距課程修正與開源補強設計

日期：2026-08-23

## 問題與證據

政大 115-1 公開課程搜尋以 `TAICA`、`臺灣大專院校人工智慧學程聯盟` 與
`人工智慧學程聯盟` 交叉查詢，都得到同一組 9 門 TAICA 課。逐一核對 9 份官方課綱後：

- 8 門明確寫「可接受非同步授課」：`070421001`、`070422001`、`070423001`、
  `070424001`、`070425001`、`070426001`、`070427001`、`070455001`。
- `070450001`「實體人工智慧」只寫同步遠距，沒有允許非同步。

目前政大搜尋結果的 `scheduleText` 對這些課多半只有「未定或彈性」。轉換器只解析
固定節次，沒有讀出課綱核實過的授課形式，因此候選課沒有正確的 `asyncAllowed` 與
預設 `attendance`；加入課表後便在非同步工作區被誤標為「時間未定」。這不只是文案
問題，也會誤導每週時段占用、實習空檔與衝堂判定。

## 核可的產品行為

1. 8 門已核實課程加入候選或更新官方資料後，標示為可同步／非同步遠距。
2. 第一次加入課表時預設採非同步，不占每週固定課表；使用者可在詳細資料切回同步。
3. 使用者主動選擇同步或非同步後，重新整理與官方更新不得偷偷覆寫該選擇。
4. 考試、課間測驗、報告與共同展示等固定活動仍顯示為單次提醒，並參與衝堂檢查。
5. `070450001` 維持同步遠距，不提供非同步選項。
6. 已存在瀏覽器中的舊 TAICA 課程會自動升級，不必刪除重加；只有尚未表達過選擇的
   舊預設資料改成非同步，保留可辨識的使用者主動選擇。
7. 「劇本寫作與 AI 協作」與「人工智慧實務專題」不因 `未定或彈性` 被猜成非同步：
   前者是密集實體授課，後者依班別選擇固定或另約時段。

## 技術設計與資料流

```text
政大 115-1 搜尋結果＋已人工核實的官方課綱
                    ↓
官方課程轉換層：依學期＋九碼課號套用 TAICA 修正
                    ↓
候選課：同步 meeting + asyncAllowed + 預設 attendance + 單次 events
                    ↓
加入／刷新／舊資料遷移共用相同規則
                    ↓
每週課表、非同步工作區、衝堂提醒與桌布匯出
```

在官方課程轉換層建立一份封閉的 115-1 核實修正表，以九碼課號為鍵，至少記錄：

- `deliveryMode` 與 `asyncAllowed`；
- 可切回同步時使用的 recurring meeting；
- 初次加入時的 `attendance: 'async'`；
- 已知的單次事件或日期待確認提醒；
- 可追溯到官方課綱的修正識別碼與說明。

不把 `TAICA`、`遠距`、`NTUCOOL` 或 `未定或彈性` 當成自動允許非同步的充分條件。
這能避免把 `070450001` 或非 TAICA 的彈性課誤判。加入課表邏輯應尊重課程的核實預設，
而官方刷新與儲存遷移必須分辨「舊的錯誤預設」與「使用者後來主動選擇」。

## 替代方案與取捨

- **採用：官方核實課號表。** 精準、可測、沒有每次開頁的網路成本；限制是新學期要重新
  核對名單。對攸關衝堂的資料，明確且保守比脆弱的自動猜測更適合。
- **備援：即時解析所有課綱。** 能自動涵蓋新課，但課綱 HTML 與文句不一致，還會增加
  外部請求、載入失敗與誤判風險，本輪不採用。
- **不採用：只改 UI 文案。** 看起來正確，底層時段與衝堂仍錯，無法達成產品目的。

## TDD 與驗收

每次只做一個垂直切片：先寫一個會因現況而失敗的測試，確認紅燈；加入最少實作後確認
綠燈，再整理命名與重複，才進下一門或下一種行為。

1. 先以一門 TAICA 課重現 `未定或彈性 → 時間未定`，再讓它成為可非同步且預設非同步。
2. 逐一加入其餘 7 門的核實資料，每門各自紅 → 綠；確認同步 meeting 仍可在切換後使用。
3. 為 `070450001` 寫反例，確認同步遠距不會被放寬成非同步。
4. 加入單次活動；沒有可靠時間的只產生待確認提醒，不建立假的衝堂區間。
5. 補舊資料遷移與官方刷新測試：修正舊預設、保留使用者主動選擇。
6. 補 UI／rendered HTML 測試，確認標籤為「非同步」而不是「時間未定」。
7. 跑全套 unit、build、rendered HTML、lint 與 NCCU live contract。
8. 使用真實搜尋 → 加入候選 → 加入課表 → 切換同步 → 重載的流程驗收；桌機
   1280×800 與手機 375×812 至少兩輪截圖，並檢查 console 與橫向捲動。

## 開源補強

Repository 目前已是 GitHub Public、採 MIT License，且已有 README、SECURITY、CI 與
GitHub Pages。這一輪補齊：

- `CONTRIBUTING.md`：本機開發、TDD、資料更正需附官方來源、PR 流程；
- `CODE_OF_CONDUCT.md` 與 Issue／PR templates；
- README 的「非政大官方服務」、資料時效與 TAICA 修正維護方式；
- 目前檔案與完整 Git 歷史的敏感資訊掃描，結果只記錄類型與結論，不輸出祕密值。

`package.json` 的 `private: true` 保留；它只防止誤發 npm 套件，不影響 GitHub 開源。

## 限制

- 名單只涵蓋政大 115-1，下一學期必須重新核實，不能沿用授課形式與考試日期。
- 「可接受非同步」不等於所有活動都免同步；最終仍以教師與聯盟最新公告為準。
- 上游官方資料若互相衝突，產品只能誠實標記待確認，不能替學校決定正確答案。
